# «Мы вдвоём» — Telegram Mini App для пары

Всё приложение — один файл `index.html`. Сервер не нужен.

## Как получить ссылку на приложение в Telegram (≈10 минут)

### 1. Выложить файл в интернет (GitHub Pages, бесплатно)
1. Зарегистрируйся на https://github.com (если ещё нет аккаунта).
2. Нажми **New repository** → имя, например, `love-app` → **Public** → **Create repository**.
3. Нажми **uploading an existing file** и перетащи `index.html` → **Commit changes**.
4. Открой **Settings → Pages** → Source: **Deploy from a branch**, Branch: **main**, папка **/ (root)** → **Save**.
5. Через 1–2 минуты сайт будет доступен по адресу `https://ТВОЙ_ЛОГИН.github.io/love-app/`.

(Альтернатива без GitHub: https://app.netlify.com/drop — перетащить папку с `index.html`.)

### 2. Создать бота и подключить приложение
1. В Telegram открой **@BotFather** → `/newbot` → придумай имя и username (например, `MashaPetyaLoveBot`).
2. `/newapp` → выбери бота → название, описание, картинка 640×360 (можно любую) →
   GIF пропусти (`/empty`) → **Web App URL**: адрес из шага 1 → короткое имя, например `app`.
3. BotFather пришлёт ссылку вида **`https://t.me/MashaPetyaLoveBot/app`** — это и есть ссылка на приложение.
4. Дополнительно (кнопка в чате с ботом): `/mybots` → бот → **Bot Settings → Menu Button** → вставь тот же URL.

## Как пользоваться вдвоём
- Вкладка **«Мы»**: имена и дата начала отношений.
- **Календарь**: отмечай дни, когда ты свободен(на), и планируй встречи (время, место — откроется в Яндекс Картах).
  Если оба свободны в один день — приложение подскажет ✨.
- **Годовщины**: счётчик дней вместе, ближайшая годовщина, свои даты (первый поцелуй, дни рождения), круглые даты (100, 500, 1000 дней).
  За 7 дней до важной даты сверху появляется напоминание.
- **Синхронизация**: «Мы» → «Отправить код» → половинка вставляет код у себя → календари объединяются.
- **Напоминания на телефоне**: «Добавить в календарь телефона» — скачивается .ics с напоминанием за день.

Данные хранятся в облаке Telegram (CloudStorage) у каждого из вас и доступны на всех ваших устройствах.
